Stage B 運用ガイド：目的・変更・証拠・未解決・次作業

同一Projectと固定version/hash/generationで、次の順に正本を確認します。

  1. 目的 — Taskのsubject、purpose、対象version/hash。
  2. 変更 — PlannedChange、ActualChange、reconciliationのbase/headと安定Path ID。
  3. 証拠 — Check、FINALIZED EvidenceVersion、Assurance/EventのRequirementSnapshot、target、generation。
  4. 未解決 — Issue、FAIL、UNKNOWN、unmapped change、active Hold reason。古い世代のPASSは現在保証にしません。
  5. 次作業 — Task state、TaskDependency、必要Approval、repair Task、次Taskを確認します。
